# la sede

Simple web application for events venue location, information and ticket purchasing link.

This project has been migrated from Create React App to Next.js and converted to TypeScript.

- **Framework**: Next.js
- **Language**: TypeScript
- **UI**: Material-UI
- **Other libraries**: framer-motion, react-scroll, react-slick (slick-carousel)

Development

1. Install dependencies:

```bash
npm install
```

2. Run in development mode:

```bash
npm run dev
```

Production build:

```bash
npm run build
npm start
```

Assets and styling remain in `public/` and `src/resources/styles.css`.

Original demo (CRA deployment): `http://green-brass.surge.sh/`
